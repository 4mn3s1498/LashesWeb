# ✨ LashesWeb

**LashesWeb** è un progetto personale di sviluppo web realizzato con HTML, CSS e JavaScript, utilizzando OpenAI Codex come assistente di programmazione sotto la mia guida.

Il progetto consiste nella realizzazione di un sito web responsive dedicato alla presentazione di uno studio estetico specializzato nella cura dello sguardo e nei trattamenti di bellezza.

## 🎯 Obiettivo del progetto

Creare una presenza online elegante, moderna e accessibile, attraverso la quale le clienti possano conoscere lo studio, esplorare i trattamenti disponibili e richiedere informazioni e appuntamenti.

## 💄 Servizi presentati

Il sito presenta quattro categorie di trattamenti:

- **Extension ciglia:** valorizzazione dello sguardo attraverso l'applicazione di extension.
- **Laminazione ciglia:** trattamento dedicato alla curvatura e alla valorizzazione delle ciglia naturali.
- **Ceretta:** trattamento per la rimozione dei peli superflui.
- **Pulizia del viso:** trattamento dedicato alla cura e alla pulizia della pelle.

## ✨ Funzionalità implementate

- Design elegante e minimalista.
- Layout responsive per desktop, tablet e smartphone.
- Navigazione con menu interattivo per dispositivi mobili.
- Sezione introduttiva dedicata allo studio.
- Galleria fotografica dei trattamenti.
- Sezione illustrativa Prima & Dopo.
- Presentazione dei servizi estetici.
- Sezione FAQ con domande e risposte interattive.
- Animazioni di ingresso durante lo scorrimento della pagina.
- Effetti hover sulle immagini.
- Collegamenti ai social network.
- Navigazione fluida tra le sezioni.
- Aggiornamento automatico dell'anno nel footer.

*Nota: le immagini della sezione Prima & Dopo sono illustrative e non rappresentano risultati reali dello studio.*

## 📱 Responsive Design

L'interfaccia è progettata per adattarsi a diverse risoluzioni:

- Desktop
- Tablet
- Smartphone

Sono stati utilizzati CSS Grid, Flexbox e Media Queries per organizzare gli elementi e adattare il layout alle dimensioni dello schermo.

## 🚀 Avvio del progetto

1. Clonare o scaricare il repository.
2. Aprire la cartella del progetto con Visual Studio Code.
3. Avviare il file `index.html` nel browser oppure utilizzare l'estensione Live Server.
